# Summary Quality Checklist

Use this checklist before delivering a summary to ensure it meets the standard.

---

## ✅ Completeness

- [ ] The summary covers all major sections of the document
- [ ] No important findings, obligations, or arguments were omitted
- [ ] Key data points, statistics, and dates are included where relevant
- [ ] The document's conclusion or final recommendation is clearly captured

---

## ✅ Accuracy

- [ ] All facts match what's in the document (no hallucinations)
- [ ] Numbers, names, and dates are correct
- [ ] The document's position is represented fairly — not twisted or editorialized
- [ ] Ambiguous or uncertain content is flagged as such

---

## ✅ Clarity

- [ ] A reader with no prior context would understand the summary
- [ ] Jargon is explained or avoided unless the audience clearly expects it
- [ ] The summary follows the correct template for the document type
- [ ] Sections are clearly labeled and easy to scan

---

## ✅ Proportionality

- [ ] The summary length matches the document length (see table in SKILL.md)
- [ ] More space is given to more important sections
- [ ] Boilerplate / filler content in the original is appropriately condensed

---

## ✅ Formatting

- [ ] Markdown is used so the output renders nicely
- [ ] Bullet points are used for lists, not long run-on paragraphs
- [ ] Emojis from the template are used to help scannability
- [ ] The "Bottom Line" or "Key Takeaway" section is present and crisp

---

## ✅ User Experience

- [ ] The user is offered the chance to go deeper after the summary
- [ ] If applicable, any disclaimers (legal, medical, financial) are included
- [ ] If the PDF couldn't be read, the user is clearly told why and given options
